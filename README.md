
# MEGA-T

## Descrição do projeto
O meu projeto de TCA o MEGA-T foi inspirado em jogos Beat'em Up (99 vidas) e em jogos que seu objetivo é matar todos os inimigos da fase e avançar para a proxima fase até chegar no BOSS (Megaman).

A jogabilidade tem como principais ações a ação de atirar que dispara um tiro no inimigo e o de escudo que cria um escudo na sua frente que defende voce de ataques.
